Design Tokens Example

This page demonstrates the use of CSS custom properties generated from JSON design tokens. All the typography, colors, spacing, and other design values are defined in the tokens.json file and automatically converted to CSS.

Features

The system automatically converts nested JSON structures into CSS custom properties. This allows designers to maintain a single source of truth for design tokens in JSON format, while developers can use the generated CSS in their applications.

Typography System

All typography values including font sizes, line heights, and letter spacing are defined as design tokens. This ensures consistency across the entire application.

Color Palette

Colors are organized by context (backgrounds, buttons, typography) and mode (light/dark), making it easy to maintain a consistent color system.
